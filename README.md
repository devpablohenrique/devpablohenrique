## ⭐ Projeto em destaque

### CasaSaldo

O **CasaSaldo** é um sistema de controle financeiro familiar criado para centralizar e organizar receitas, despesas, contas, cartões de crédito, categorias, parcelamentos e competências mensais.

O sistema está sendo desenvolvido com foco em uma arquitetura organizada, segurança, regras de negócio bem definidas, testes automatizados, versionamento do banco de dados e evolução contínua.

### Principais tecnologias

* Java 21
* Spring Boot
* Spring Data JPA
* Spring Security
* PostgreSQL
* Flyway
* Maven
* Docker
* Angular
* TypeScript

### Principais características

* Gestão financeira por família
* Suporte a múltiplos usuários
* Controle de receitas e despesas
* Gerenciamento de contas financeiras
* Categorias de receitas e despesas
* Controle de cartões de crédito
* Parcelamento de despesas
* Controle por competência mensal
* Fechamento e reabertura de competências
* Exclusão lógica de registros
* APIs REST versionadas
* Autenticação e autorização
* Testes automatizados
* Banco de dados versionado com migrations

### Objetivo técnico

Além de atender a uma necessidade de organização financeira familiar, o CasaSaldo também é utilizado como projeto de evolução profissional, permitindo aplicar conceitos como:

* Arquitetura em camadas
* Modelagem de domínio
* Regras de negócio
* DTOs e mapeamento de dados
* Validação de requisições
* Tratamento global de exceções
* Segurança de APIs
* Testes unitários e de integração
* Versionamento de banco de dados
* Conteinerização da aplicação
* Integração entre backend e frontend
* Documentação técnica
* Boas práticas de desenvolvimento
