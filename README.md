## Projeto em destaque

### CasaSaldo

O **CasaSaldo** é um sistema de controle financeiro familiar desenvolvido para organizar receitas, despesas, contas, cartões de crédito, categorias, parcelamentos e competências mensais.

O projeto está sendo construído com foco em boas práticas de desenvolvimento, arquitetura organizada, segurança, validações de negócio, testes automatizados e evolução contínua.

#### Principais tecnologias

* Java 21
* Spring Boot
* Spring Data JPA
* Spring Security
* PostgreSQL
* Flyway
* Maven
* Docker
* Angular
* TypeScript

#### Principais características

* Gestão financeira por família
* Suporte a múltiplos usuários
* Controle de receitas e despesas
* Categorias de lançamentos
* Contas financeiras
* Cartões de crédito
* Parcelamento de despesas
* Controle por competência mensal
* Fechamento e reabertura de competências
* Exclusão lógica de registros
* APIs REST versionadas
* Testes automatizados
* Banco de dados versionado com migrations

#### Objetivo técnico

O CasaSaldo também funciona como um projeto de evolução profissional, permitindo aplicar conceitos como:

* Arquitetura em camadas
* Modelagem de domínio
* Regras de negócio
* DTOs e mapeamento de dados
* Tratamento de exceções
* Segurança de APIs
* Testes unitários e de integração
* Versionamento de banco de dados
* Conteinerização
* Integração entre backend e frontend

[Ver repositório do CasaSaldo](https://github.com/devpablohenrique/CasaSaldo)
